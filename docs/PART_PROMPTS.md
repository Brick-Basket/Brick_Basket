# BrickBasket — Part-by-Part Build Roadmap

This is the working plan for building the whole frontend in controlled units, exactly as `BrickBasket_Master_Frontend_Prompt_v6.1` requires ("do not generate the entire application in one response... work in controlled feature units"). Each part below is a **self-contained prompt** — paste it as-is to kick off that part in a session that has this project attached. Do them in order; each depends on the ones before it. After each part, the assistant updates `CHANGELOG.md` and the relevant `docs/*.md` file(s) and stops for review before continuing.
